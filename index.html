How this reaction time test works

The test uses five valid rounds. After you start, the page waits for a randomized interval before changing the test state. Your response time is measured with the browser's high-resolution performance timer.

  • Five rounds per session
  • Randomized waiting period
  • Mouse, touch, Space and Enter input
  • Early clicks are treated as false starts

How accurate is the result?

A browser test can measure your response within the browser timing environment, but your result also reflects display refresh rate, input-device latency, operating-system load and other hardware factors.

For consistent comparisons, use the same device, browser and input method whenever possible.

What is a good reaction time?

Reaction time varies between people and between test setups. Our rating labels are intended as a simple benchmark for this site, not as a diagnosis or professional performance certification.

Average human reaction time

Visual reaction times are often discussed in the low-hundreds-of-milliseconds range, but there is no single number that represents every person or every testing method. Input hardware and test design matter.
